# Countdown Timer

A simple, clean countdown timer web app. Set minutes, then start, pause, or reset the timer. Features a large digital display. No sound is played.

## Features

- Set countdown time in minutes
- Start / Pause / Reset controls
- Big digital MM:SS display
- Clean, modern, responsive design
- No sound

## Tech

- Plain HTML, CSS, and JavaScript
- No build step, no dependencies
- Single `index.html` file

## Structure

```
.
├── index.html   # The entire app (HTML + CSS + JS)
└── README.md    # This file
```

## Usage

Open `index.html` in any modern web browser. No server or installation required.

1. Enter the number of minutes.
2. Click **Start** to begin the countdown.
3. Click **Pause** to pause, **Start** again to resume.
4. Click **Reset** to return to the set time.
