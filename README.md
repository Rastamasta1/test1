# Welcome Project

A simple static HTML project featuring a welcoming home page.

## Project Purpose

This project provides a clean, minimal welcome page built with plain HTML and CSS. It demonstrates a basic HTML5 page structure with modern styling using system fonts, a card layout, and a subtle shadow effect.

## Project Structure

```
.
├── index.html   # Main welcome page
└── README.md    # This file
```

## How to View index.html

### Option 1: Open Directly in a Browser

1. Clone or download this repository.
2. Navigate to the project folder.
3. Double-click `index.html` or open it with your browser:
   - **macOS:** `open index.html`
   - **Windows:** `start index.html`
   - **Linux:** `xdg-open index.html`

### Option 2: Use a Local Development Server

If you have Python installed:

```bash
# Python 3
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.

If you have Node.js installed:

```bash
npx serve .
```

Then visit the URL shown in the terminal output.

### Option 3: View on GitHub Pages

If this repository has GitHub Pages enabled, the page is accessible at:

```
https://<your-username>.github.io/<repository-name>/
```

## What the Page Displays

- A centered card with a welcome heading and introductory text.
- A "Getting Started" badge at the bottom of the card.
- Clean, responsive styling using system fonts and a light background.
