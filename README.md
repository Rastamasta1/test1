# Hello World Web Page

A simple hello-world web page with a button that shows an alert. No build step, no dependencies.

## Structure

```
.
├── index.html   # The full page (HTML + inline CSS + inline JS)
└── README.md    # This file
```

## Features

- Clean, centered layout with a friendly greeting.
- A **Click Me** button (`id="greetBtn"`) that shows a `Hello, World!` alert.
- Responsive: includes a `meta viewport` tag so it looks good on mobile.
- Custom emoji favicon (inline SVG data URI).

## Usage

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser:
   - Double-click the file in your file explorer, **or**
   - Drag it into a browser window, **or**
   - Run `open index.html` (macOS), `start index.html` (Windows), or `xdg-open index.html` (Linux).
3. Click the **Click Me** button to see the `Hello, World!` alert.

No installation, build tools, or server required.

## Development

All HTML, CSS, and JavaScript live inside `index.html`. To make changes, edit that single file and refresh the browser.
